# 📊 Sales Data Analysis

## 📌 Project Overview
This project analyzes a sales dataset using Python and pandas to extract key insights like total sales, best-selling product, and statistical metrics.

---

## 🎯 Objectives
- Calculate total sales
- Identify best-selling product
- Perform basic data analysis

---

## 🛠 Tools Used
- Python
- Pandas

---

## ⚙️ How to Run
1. Install pandas:
   pip install pandas
2. Run the script:
   python sales_analysis.py

---

## 📊 Results
- Total Sales: ₹12365048  
- Best Selling Product: Laptop  
- Average Sales: ₹123650.48  
- Highest Sale: ₹373932  
- Lowest Sale: ₹6540
